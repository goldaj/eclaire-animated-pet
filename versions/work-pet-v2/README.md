# Variante native Work Pet v2

Sprite sheet et planches de contrôle issus de la création originale de ce compagnon. Cette version complète la démonstration et les animations déjà présentes dans le dépôt ; elle conserve son format natif WebP et ses directions de regard.

- `spritesheet.webp` : planche native.
- `contact-sheet.png` : vue de contrôle des animations.
- `look-directions.png` : vue de contrôle des directions de regard.
- `previews/` : prévisualisations de l’artefact original.

Les métadonnées privées de session, identifiants de compte, chemins locaux et rapports techniques internes ne font pas partie de cette archive publique. L’intégration dans un environnement de compagnon reste propre à cet environnement ; cette variante ne remplace pas les fichiers utilisés par la démonstration web existante.
